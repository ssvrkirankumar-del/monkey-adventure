## 1. Executive Summary & Objective

The primary objective of **Step 1** is to perform a comprehensive, non-destructive dependency audit across the entire **Monkey Adventure** project. This establishes a clean, stable foundation for cinematic 3D visual upgrades without risking gameplay mechanics, player physics, combat systems, AI behavior, puzzle progression, colliders, or scene logic.

### 🛡️ Core Rules & Safety Invariants
1. **Zero Gameplay Destruction:** No scripts, tags, layers, character controllers, physics colliders, triggers, or animators are modified or deleted.
2. **Zero Code Deletions:** All gameplay components (`MonkeyPlayerController`, `GuardianCombat`, `EnemyAI`, `AncientDoor`, `RuneSwitch`, `Checkpoint`, `ThirdPersonCamera`, `LevelProgressionManager`) are preserved and protected.
3. **Visual Decoupling:** Placeholder visual geometry (spheres, capsules, cylinders) is decoupled from physics colliders and disabled via child `[HD_Visual]` overrides.

---

## 2. Asset Classification Taxonomy

Every asset in the project has been categorized under one of the 8 canonical classes:

| Class | Definition | Action Policy |
| :--- | :--- | :--- |
| **1. REQUIRED GAMEPLAY** | Scripts, player controllers, combat systems, boss logic, AI, puzzles, checkpoints, physics colliders | **LOCK & PRESERVE** (100% Intact) |
| **2. REQUIRED VISUAL** | URP Particle VFX prefabs, core gameplay materials, URP settings & volume profiles | **KEEP & OPTIMIZE** |
| **3. APPROVED HD ASSET** | Scanned 3D meshes (FlipGameDev FBXs, Procedural Tree Oak/Elm/Magnolia, Furry Squirrel 3D model, Supercyan Forest items) | **ACTIVE PRODUCTION ASSETS** |
| **4. OPTIONAL** | Stylized low-poly asset packs, auxiliary tool meshes (Polytope, CoolWorks, Low Poly Kit) | **PRESERVE / SECONDARY USE** |
| **5. DUPLICATE** | Redundant root scenes, duplicate editor scripts, duplicate backup directories | **SAFE TO ARCHIVE** |
| **6. LOW-POLY PLACEHOLDER** | Procedural sphere/capsule/cylinder meshes and prefabs generated by legacy primitive tools | **DISABLE RENDERERS ONLY** (Keep Colliders) |
| **7. UNUSED TEST ASSET** | Temporary one-off scripts and empty directories | **SAFE TO ARCHIVE / CLEANUP** |
| **8. SAFE TO ARCHIVE** | Obsolete procedural primitive generation scripts and redundant tool iterations | **ARCHIVE TO BACKUP** |
